# Human GVC — Human Genome Variant Calling Platform

Platform web untuk otomasi analisis variant calling data genomik manusia,
dari unggah data sekuens FASTQ hingga hasil varian tersimpan di basis data bersama.

## Anggota Kelompok
- Dhafin Fasya Arifin — Project Manager
- Yafits — System Analyst
- Abid — Frontend Developer
- Rakazaki — Backend Developer
- Fattha — Tester

## Struktur Proyek
- `frontend/` — antarmuka pengguna
- `backend/` — API dan job manager
- `database/` — skema dan migrasi basis data
- `docs/` — LKP 6-11
