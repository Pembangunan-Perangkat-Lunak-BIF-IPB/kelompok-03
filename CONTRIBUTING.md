# Aturan Kerja Kelompok

## Branch
- Jangan commit langsung ke `main`
- Nama branch: `feat/nama-fitur`, `fix/nama-perbaikan`, `docs/topik`, `setup/nama-setup`, `database/nama-perubahan`

## Commit
- Tulis pesan yang jelas, contoh: "Tambah skema tabel sampel"
- Jangan tulis "update" doang

## Pull Request
- Semua kerjaan lewat PR, minimal 1 reviewer dari anggota lain
- Tulis "Closes #nomor-issue" di deskripsi PR
